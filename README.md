# Student Marks Prediction Using Machine Learning

## Project Overview
This project predicts student marks based on daily study hours using a Linear Regression model.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Gradio
- Google Colab

## Features
- Sample dataset creation
- Data visualization
- Linear Regression model training
- Student marks prediction
- Model evaluation
- Interactive web application
- Prediction results table

## Files Included
- `Student_Marks_Prediction.ipynb` — Python code and experiments
- `student_marks_model.pkl` — Trained machine learning model
- `Student_Marks_Prediction_Report.txt` — Project report
- `Student_Marks_Prediction_Graph.png` — Prediction graph
- `Student_Marks_Prediction_Results.csv` — Prediction results

## How It Works
The model learns the relationship between study hours and marks from a sample dataset. Users can enter their study hours into the application to receive predicted marks.

## Algorithm
Linear Regression

## Disclaimer
This is an educational demonstration using a small sample dataset. Predictions are not guaranteed real-world exam results.
